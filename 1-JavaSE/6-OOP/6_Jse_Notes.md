# 类的概念
“类”是对一类事物的抽象。“对象”是“真实存在”的。  
举例：计算机是一个类，我现在使用的电脑是其中的一个对象

# 类的声明结构：
## 实体类
- 可参考 [Person.java](src/Person.java)
```
[修饰符] class 类名{
    属性（即成员变量）
    方法（即成员函数）
}
```
## 基于类创建对象（实例化/测试类/主类）
- 可参考 [PersonObject.java](src/PersonObject.java)
```
类名 变量名/对象名 = new 类名();
例如：Person p = new Person();
```
在对象类的文件中，可以调用类中声明的方法,如`p.eat();`
