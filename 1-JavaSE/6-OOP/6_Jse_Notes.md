# 类的概念
“类”是对一类事物的抽象。“对象”是“真实存在”的。  
举例：计算机是一个类，我现在使用的电脑是其中的一个对象

# 类的声明结构：
## 实体类
- 可参考 [Person.java](src/person/Person.java)  
```
[修饰符] class 类名{
    属性（即成员变量）
    方法（即成员函数）
}
```
## 基于类创建对象（实例化/测试类/主类）
- 可参考 [PersonObject1.java](src/person/PersonObject1.java)  
```
类名 变量名/对象名 = new 类名();
例如：person.Person p = new Person();
其实，‘类名（）’就是构造方法
```
在对象类的文件中，可以调用类中声明的方法,如`p.eat();`  
构造方法与类名相同，没有返回值，也没有void关键字。  
构造方法是用来创建对象的，如果类中没有手动声明构造方法，那么编译器会默认生成一个无参构造方法  
也就是`Person p = new Person();`明明在Person类中没有构造方法，但是`new`关键字后面调用的就是默认提供的无参构造方法  
那么，如果手动声明构造方法，那么执行上方语句时也会执行方法体



# 对象的底层类似于指针
- 可参考 [PersonObject2.java](src/person/PersonObject2.java)  
同类的对象在互相赋值后，底层指针会指向同一块内存空间，改变一个对象的属性，另一个对象属性也会改变  
对象作为方法的传参时，调用方法，方法外部的对象属性会根据方法处理而改变  
与之容易混淆的就是变量的传参，变量作为参数传递到方法内部进行处理时，方法外部的变量不会改变
# 类的组合
- 可参考 [PersonCar.java](src/person/PersonCar.java)  
也称对象之间的协作。  
即：一个类可以有另一个类的对象作为属性，并且可以调用那个对象的方法  
[Car](src/person/Car.java)实体类中定义的方法被[Person](src/person/Person.java)中的方法调用了，不过前提是`Car`作为`Person`的属性  
这钟关系常常适用于现实中具有组合关系的对象，在开发时符合现实逻辑
